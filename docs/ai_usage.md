# AI辅助使用记录

## 阶段0用途

AI用于读取课程材料、整理要求矩阵、起草项目结构、SQL模型、Docker Compose、环境检查命令和数据源验证方案。AI也提出了电影/人物匹配、血缘和恢复接口的设计建议。

## 阶段1用途

2026-11-03，AI辅助起草评论流式解析器、PostgreSQL迁移与事务装载器、构造测试、故障注入和Airflow DAG。所有事实统计均来自本机真实命令和数据库查询：真实前1000条解析、两个独立测试数据库的幂等/恢复测试、业务库Airflow运行及日志。AI没有生成评论事实、人工标签或全量统计。

人工验证方式包括：学生授权并观察环境运行；实际格式与初始假设不符时以真实helpfulness值修正规则；非法UTF-8不静默丢弃；提交前/后故障均以数据库计数和检查点复核；同ID异内容使用明确标记的构造数据测试，未冒充真实冲突。

阶段1修正中，AI辅助实现v2解析器、003迁移、COPY集合装载原型、异常数据库验收与Airflow重试测试。真实前1000条、1000/10000条性能数据、7条编码错误位置和所有数据库计数均来自本机实际命令；构造异常记录明确标记为`constructed_database_acceptance`。AI未把单字节异常推断成某个备用编码，也未生成事实标签。

## 阶段2用途

2026-11-03，AI辅助实现v3全量入口、004迁移、EOF/覆盖验证、磁盘停止阈值、Airflow全量DAG和短文件/损坏gzip构造测试。100000条扩大验证、全量批次进度、数据库/WAL/磁盘数据及最终核对均以本机程序、PostgreSQL和Airflow日志为依据；官方7911684/253059/889176仅作为作业给定比较基准，不用于修改或补齐本地结果。

首次全量Airflow运行出现5,564秒调度器心跳中断；宿主休眠是可能原因，但Windows系统事件因权限不足未核实，因此不写成已证实事实。该事件同时暴露了失败叶任务可能掩盖上游失败的问题。AI辅助修正DAG后，从已提交检查点恢复；原始记录、卷和历史解析结果均未删除。

最终全量事实均来自本机数据库和日志：7,911,696个物理块、7,849,544有效、62,152隔离；其中12个畸形块缺少ASIN/用户，可靠ASIN评论7,911,684，产品253,059，可靠用户889,176。AI只辅助查询和解释字段序列，没有修改数据以匹配官方数字。

Docker Desktop磁盘迁移前，AI辅助安全停止、记录计数并生成D盘VHDX备份；备份SHA-256由本机计算并匹配。Secrets Engine stale socket错误依据本机错误1920和Docker官方问题记录，采取可回退的父目录重命名，由学生在普通PowerShell执行。未恢复出厂、删除卷、删除WAL或注销WSL发行版。

## 阶段3用途

2026-11-03，AI辅助实现005迁移、UCSD有界流适配器、商品分类基线、IMDb候选验证、字段级血缘、Scrapy单页采集器和Airflow小样本DAG。事实值来自本机实际HTTP响应与数据库：UCSD 6/6命中、记录位置和ETag；IMDb建议JSON；Wikipedia支持摘要；Amazon验证页快照及哈希。AI没有把自身知识写入事实表，也没有生成human_label。

第一次候选规则错误地要求支持摘要与商品剧情描述达到整段文本相似阈值；真实摘要不包含剧情但明确包含年份和导演。规则依据可定位字段修正为标题、双来源年份、人物和导演联合证据，旧复核项保留为resolved。第一次Scrapy 2.19接口未调度请求的运行也保留并纠正为failed。所有修正均通过真实重跑和关系计数核对。

用户随后手动启动UCSD真实全量入口。AI只读取本机运行39、检查点和数据库关系进行验收并更新文档，没有修改数量以接近网页声明值。真实结果为203,766条JSONL、73,813个本地ASIN命中、29.1683%覆盖；网页声明203,970只作比较。14,847个重复ASIN经数据库核对均无规范标题或分类冲突。

## 阶段4用途

2026-11-04，AI辅助实现首批50个电影开发样本筛选、IMDb有界候选生成、证据/冲突保存、006迁移、TSV导出和Airflow小样本DAG。32/17/1的状态、IMDb响应、数据库外键、测试和DAG成功状态都来自本机真实运行；AI自身知识没有写入事实表，也没有生成`human_label`。

首个Airflow重跑暴露了选择表删除与候选外键冲突，真实失败日志被保留；修复为幂等更新后重新触发成功。算法只允许“标题+独立人物交叉证据”进入`rule_verified`，标题相同但缺乏其他证据的候选仍为待复核。该状态仍是算法预测，不是学生人工确认，也不能用于计算无独立标签的准确率。

阶段4缓存修正中，AI辅助实现逐候选证据评估、类型冲突、人物原文位置和具体人工复核问题。第一次v2草案因长篇编辑评论中的“TV movie”比较语句误判Vacancy类型；该草案run 49保留，规则收窄为标题加首段商品摘要后以v2.1/run 51重算。最终35条规则确认、1条多候选歧义、11条证据不足、2条缓存无合适候选、1条空候选池均来自数据库缓存重评；没有新增HTTP来源，也没有填充50个空白`human_label`。

阶段4 v3中，AI辅助实现全部缓存tt候选提取、Unicode标题双形式、人物上下文分类、年份/类型/编号边界、固定证据分、五条确认路径、独立标签表和Airflow缓存重跑。311个候选和31/1/14/3/1统计来自本机缓存与数据库。AI没有新增网络请求，也没有填写人工标签；空模板导入实际为0条。The Red Baron角色/演员、Frozen同名作品、Resident Evil同系列演员歧义、Castle Rock类型冲突和UFC体育集锦均由可定位缓存/UCSD证据产生，不依赖AI常识。第一次DAG验证因跨版本联接计成200而失败，修正后最终连续两次成功且内容摘要一致，失败日志仍保留。

2026-11-05，学生本人通过聊天提交5个development商品的6项人工标签。AI只把学生原话与数据库中已有UCSD source_record、IMDb候选ID/URL及缓存响应定位整理为`human_evidence`，没有补造导演、年份或演员事实，也没有把“本次未找到UFC第8部”改写为IMDb不存在该条目的断言。首次导入6项、重复导入0新增均由本机数据库验证；这些标签不计入独立评价集。

随后AI按学生要求只审计现有14条证据不足记录，未联网。通用actor/host、stars、top-billed、performance/portrayal、前置演员列表和前置冠词提取修正以新规则版本v3.1保存，旧v3未覆盖；5条状态升级均可定位到UCSD原片段。统一采用逻辑由数据库视图执行：人工决定优先，其余v3.1规则确认可自动采用。人工4、规则34、排除1、暂缓11来自本机SQL，不是AI主观计数。

## 阶段5用途

2026-11-05，AI辅助实现IMDb固定快照清单、选择性流式装载、nconst人物与关系证据、事务检查点、故障注入和Airflow DAG。5文件大小、SHA、gzip EOF、记录数及`tt0078764`标题/人物/角色全部来自学生下载的本机固定快照；AI知识没有写入事实字段。首次真实扫描的CSV字段上限错误保留并以逐行TAB解析修复，随后实际读完大型akas/principals文件。

真实人物合并只在数据库证据满足“姓名一致、两边由不同SourceRecord关联同一已确认tconst、nconst候选唯一”时由规则生成；AI没有按常识或姓名单独合并人物。`title.principals`没有被描述成完整演员表或主演。构造恢复数据明确保存在独立测试库；业务库正式独立评价标签仍为0，AI未预填评价答案或生成指标。

## 不允许的用途

AI输出不作为电影标题、上映日期、演职员、ASIN映射或人物身份的事实来源；不把AI判断写成人工标注；不伪造页面访问、全量统计、准确率或运行日志；不绕过验证码、登录和封禁。

## 阶段7用途

2026-11-06，AI辅助整理可执行血缘/业务查询、反向来源影响视图、报告草稿、ER图、Airflow恢复与干净环境复现脚本。AI没有读取、导入或改写学生正在填写的person v2答案，也没有读取person v2冻结预测或生成正式人物指标。新增SQL在Docker引擎恢复前明确标为“代码已实现、数据库未实跑”，未用静态存在冒充验收。

Docker Desktop自动启动复发Secrets Engine残留socket权限故障。AI只停止未提供服务的失败进程并尝试可回退目录重命名；没有删除卷、VHDX、WAL、数据库或原始文件。权限阻止自动修复后，问题被保留为实际验收阻塞。

学生完成person v2的100条盲评后，AI仅校验编号/标签/理由、保持原始理由、导入数据库并读取此前冻结的预测计算指标；没有替学生生成或修改标签。人物原始XLSX归档哈希与桌面文件一致，首次导入100、重复导入0。姓名类别由固定Unicode规范化和SequenceMatcher阈值从左右姓名派生，不覆盖人工实体标签。

AI辅助整理development案例时只使用已保存的UCSD字段位置、阶段4缓存、固定IMDb快照关系和已有人工否定。三条人物变体合并要求同一已采用tconst及明确双源署名；五条人物/电影不合并要求年代、作品、类型或编号硬冲突。电影跨版本只有同标题而缺少充分证据的两条继续保持候选，没有为达到数量伪造确认。

2026-11-06最终收尾中，AI重新检查了跨版本候选的UCSD原始描述、分类路径、固定IMDb title/principal记录和正式评价排除范围。Chocolate在多项演职员与详细规格支持下确认，同时保留地区字段冲突；The Crazies因1973原版与2010重拍版被明确拒绝。另确认The Color of Money、Initial D、Journey to the Center of the Earth和The Rundown，共5组。决定由数据库约束和实际“作品全部商品版本”查询复验，不使用网络或AI常识作为事实来源。

## 人工验证方式

- 学生逐条核对作业说明与 `docs/requirements_matrix.md`，以原文为准修正遗漏。
- 每个外部字段必须链接 `raw.source_record` 和具体字段定位；没有原始证据的建议不得进入最终字段。
- 电影和人物人工评价集由学生依据多个可定位来源独立确认，并记录标注时间、依据和分歧处理。AI不得填充 `human_label`。
- 所有AI生成代码在独立命令、小批量数据库事务和失败注入中验证后，才由Airflow调用。
- 每阶段报告只陈述实际执行的命令与结果，未运行组件明确标记为未验证。
